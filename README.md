# 5hubh4m.github.io

A website for hosting some of my work.

The website is written in `Jekyll` using the theme [no-style-please](https://github.com/riggraz/no-style-please), install dependencies by running `bundle` in the project root.

The code exists in the `develop` branch. Running `build.sh` in the project root directory should publish the website to the `master` branch.

Feel free to modufy and use it for your own websites. Add more projects and publications by adding to `_data/projects.yml` and `_data/publications.yml`. You can add more links on the home page in `_data/menu.yml`.
